# inference-algorithms Specification

## Purpose

为业务服务与独立计算建立稳定的数据和错误契约，使 service 能根据固定版本准备输入并解释结果；以明确非医学用途的心率／呼吸率场景模板和合成 PPG 示例验证链路，不把未实现算法或示例诊断当作真实健康预测。

## Requirements

### Requirement: 算法契约独立于业务框架
计算接口 MUST 声明所需输入文件、制品、资料字段、参数和结果规则，只接收已准备的文件引用、固定参数及资料快照，返回完整结果、可投影值和允许的输出文件；不得依赖业务 ORM、HTTP 请求或读取实时资料。

#### Scenario: 在非 Web 环境执行
- **WHEN** 独立执行环境向合法算法提供固定输入、参数和快照
- **THEN** 算法可以按其契约执行，不需要 HTTP 请求或数据库用户资料查询

#### Scenario: 快照缺少算法必需资料
- **WHEN** 算法要求的资料字段在已提交快照中缺失
- **THEN** 计算准备阶段返回明确资料失败，不能读取实时资料或以未知默认值掩盖缺失

### Requirement: 算法注册受控且版本解释稳定
系统 MUST 仅接受受控注册且具有可执行实现的算法标识，注册元数据说明示例属性和输入输出规则；未知或未实现标识不能用于发布可执行版本。不兼容契约变化 MUST 使用新标识，不能改变旧已发布版本的解释。

#### Scenario: 使用未实现正式算法
- **WHEN** 管理人员请求发布只有接口模板而没有真实实现的正式心率／呼吸率算法
- **THEN** 系统拒绝发布，不以示例或空实现替代正式执行器

#### Scenario: 同版本历史任务解释
- **WHEN** 查询或恢复一个已提交固定版本任务，同时系统已增加其他算法版本
- **THEN** 该任务仍使用原标识的输入输出契约，不因新增算法而改变结果含义

### Requirement: 心率呼吸率模板参考已有 PPG 契约
系统 MUST 提供心率／呼吸率算法接口模板，明确输入逻辑名 `ppg`、毫秒时间戳、RGB 或 YUV 通道、无需权重制品，以及未来正式结果中的心率与呼吸率字段和单位；模板不得宣称已实现旧算法的滤波、质检或数值规则。

#### Scenario: 查看模板使用边界
- **WHEN** 实施者依据模板接入未来真实心率／呼吸率计算
- **THEN** 可以确定文件、资料、结果和安全失败边界，但不能将模板或示例解释为已经实现医学算法

### Requirement: 示例执行返回真实输入诊断而非健康数值
系统 MUST 提供可执行 `hr_br.example`，从实际 PPG 文件读取并产生样本数、时长和采样率等输入诊断，完整输出包含 `example: true`；不得输出固定或虚构的 `hr`／`br`，不得把示例指标投影到正式健康指标代码。

#### Scenario: 处理合法合成样本
- **WHEN** 示例执行器处理时间戳和通道数值合法的合成 PPG 文件
- **THEN** 样本数对应实际行数、时长与采样率对应实际毫秒时间戳，结果明确为示例且不含心率／呼吸率预测

#### Scenario: 输入文件变更
- **WHEN** 两个示例任务上传具有不同合法样本数或时长的 PPG 文件
- **THEN** 输出诊断反映各自实际输入，不用同一固定成功载荷响应两者

#### Scenario: 无效示例输入
- **WHEN** 文件缺少规定列、样本不足、数值非有限或时间戳不严格递增
- **THEN** 示例执行返回安全输入失败，不填默认健康数值或生成成功诊断

### Requirement: 示例身份不可由客户端隐藏
系统 MUST 从算法定义确定示例身份，在可用模型、任务摘要和任务详情中公开 `isExample`，成功结果保留示例标志；客户端参数或版本命名不得将示例变成正式预测。

#### Scenario: 将示例版本命名为正式版本
- **WHEN** 示例算法被配置在名称不包含 example 的模型版本中
- **THEN** 模型与任务仍显示示例标志，版本名称不能掩盖非医学用途

### Requirement: 合成示例数据可重复使用且不含真实健康资料
系统 MUST 提供可直接上传的合成 PPG CSV，说明列名、单位、生成方式和非临床用途，不包含真实人员标识、病史或采集记录；使用示例证明 service 行为，不宣称真实算法准确性。

#### Scenario: 按开发说明提交样本
- **WHEN** 开发者按说明使用附带合成 CSV 创建并提交示例任务
- **THEN** 可以驱动独立消费并取得可核对的输入诊断，无需取得真实患者资料或模型权重

### Requirement: 运行时复用资源不混入任务状态
系统 MUST 按固定版本复用可重复使用的计算资源，任务专属路径、资料、输出和质量状态不得保存在共享运行时实例；仍被渠道或未终结任务使用的版本资源不能因切换被错误卸载，释放实例不删除制品。

#### Scenario: 同版本多个任务
- **WHEN** 同一版本先后或并发处理两个输入和输出目录不同的任务
- **THEN** 可复用资源保持共用，但各任务输入诊断、资料和输出引用相互独立

#### Scenario: 切换后旧任务仍待执行
- **WHEN** 渠道已经切换到新版本，旧版本仍有已提交或运行任务
- **THEN** 旧任务仍可以使用旧版本资源完成；排空后卸载实例也不删除旧制品或历史结果
