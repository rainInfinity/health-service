# Proposal

## Why

账号认证、健康资料和十二张业务表已经落地，但模型发布、任务上传提交、消息投递、独立执行及结果查询尚未形成可使用的 service 流程。先以心率／呼吸率场景的算法接口模板和合成 PPG 示例打通该流程，可以验证业务与恢复边界，而不把真实算法迁移或医学效果验证混入本次变更。

## What Changes

- 实现管理渠道的密码登录、Refresh 轮换和登出，所有模型管理操作同时校验账号可用状态、令牌渠道及管理权限；不开放管理账号注册。
- 实现模型、版本、制品及指标目录用例、发布校验和渠道当前版本配置；发布后的算法标识、参数、制品和投影指标集合不可原地修改。允许无权重制品的算法版本发布。
- 实现普通渠道的可用模型查询，以及本人任务草稿、文件上传／同名历史保留、最终提交、分页查询、结果详情和受保护下载。
- 最终提交冻结完整当前健康资料及提交时年龄；推理侧只使用快照。创建草稿、提交与渠道切换使用一致事务锁顺序，切换时终止旧版本草稿，不改变已提交任务的执行版本。
- 实现 Redis Streams 发布与消费、数据库补偿扫描、可续约执行租约及执行令牌隔离、未确认消息重领、终态落库后确认；不承诺恰好执行一次或 Redis 自身可用性。
- 成功状态、完整结果与指标投影同事务持久化；安全失败代码区分任务、计算和结果错误，基础设施暂时性故障不直接变成业务终态失败。
- 计算侧仅提供纯 Python 接口模板、明确标为示例的 `hr_br.example` 执行器和合成 PPG CSV。示例输出实际输入的样本数、时长和采样率诊断，不输出虚构 `hr`／`br`，不注册未实现的正式 `hr_br` 执行器。
- 实施阶段同步配置模板、开发／架构文档和行为验证；本次提案阶段只创建 OpenSpec 规划产物。

## Capabilities

### New Capabilities

- `model-catalog`：模型目录、版本发布不变性、制品和指标配置、渠道版本选择及普通渠道可见模型。
- `inference-tasks`：任务归属、草稿与上传、资料快照、提交、列表和结果查询的业务行为。
- `inference-runtime`：消息投递补偿、独立消费、执行租约、崩溃恢复、终态写入及确认语义。
- `local-file-storage`：原始输入、处理后文件和模型制品的本地存储键、完整上传登记及授权下载。
- `inference-algorithms`：业务与计算的独立接口契约、算法注册、逐版本运行时资源和非医学示例执行。

### Modified Capabilities

- `user-auth`：增加 `manager` 密码认证与渠道绑定令牌流程，并在管理访问和刷新时重检管理权限；现有普通渠道行为保持不变。
- `health-data-model`：增加任务执行令牌、租约到期时间、尝试次数及最近发布时间的持久化约束，不新增结果表、Outbox 表或改变已有任务状态枚举。

## Impact

- service 代码：`application/`、具体 `infrastructure/persistence/`、`schemas/`、`api/v1/`；沿用已求值内部数据、同步事务与异步入口，不引入通用仓储或事务框架。
- 基础设施：新增本地文件存储、Redis 队列适配、计算适配器和 `run_inference` 管理命令；Web 不执行算法或预加载计算运行时。
- 数据库：保留现有十二张业务表，在任务表增加执行与补发字段，新增迁移；结果继续以 `Task.result_payload` 为权威，指标只作查询投影。
- 依赖与配置：使用 `uv` 增加 `redis-py`；新增文件根目录、上传限额、Stream／消费组、补发及租约参数，同步 `.env.template`；不为模板引入 ONNX Runtime、NeuroKit2 或旧项目整套依赖。
- 接口：新增普通渠道模型与任务 API、管理端模型目录 API，复用统一 JSON 回复；文件成功下载不做 JSON 包装。
- 验证：PostgreSQL 事务／并发测试、Redis 实际发布和重领、示例数据端到端运行；测试按领域放入 `tests/integration/`，纯计算和存储边界放入 `tests/unit/`。
- 文档：实施时更新 `docs/architecture/backend-architecture.md`、`docs/architecture/database-design.md`、`docs/development.md`；合成示例数据及说明放在 `docs/examples/hr-br/`。
- 范围外：真实心率／呼吸率算法、旧算法数值规则、医学准确性验证、其他算法迁移、短信登录、管理账号自助注册、任务取消、草稿过期、自动健康数据删除、合批、多进程扩容、对象存储、Redis 高可用及自动 Stream 裁剪。
