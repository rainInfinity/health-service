# Spec Delta

## MODIFIED Requirements

### Requirement: 独立消费可运行且退出可恢复
系统 MUST 提供独立于 Web 的常驻消费入口及单轮运行模式，完成补发、领取、执行和确认；退出时停止新领取，不把未完成任务伪装为终态。消息保留策略不得丢弃仍需恢复的未确认任务。

#### Scenario: 单轮处理示例任务
- **WHEN** 运行单轮模式且存在输入符合已注册算法契约的已提交任务
- **THEN** 入口完成本轮有界派发和消费，并按算法契约保存结果；无消息时能退出而非永久等待

#### Scenario: 执行中停止进程
- **WHEN** 消费者在完成终态前退出
- **THEN** 未确认消息与数据库执行信息保留，租约过期后新消费者可以恢复该任务
