# Spec Delta

## ADDED Requirements

### Requirement: 糖尿病风险 v1 使用单块 PPG 和固定版本模型
正式算法 `ppg.active.offline.diabetes.v1` MUST 要求输入逻辑名 `ppg` 和 ONNX 制品逻辑名 `diabetes`，不要求健康资料或客户端元数据，不接受改变计算规则的参数。PPG CSV MUST 使用严格递增的有限毫秒时间戳 `timestampFrame` 和恰好一组完整 RGB 或 YUV 通道，每帧一行；可选 `blockIndex` MUST 为整数 0。无效输入 MUST 明确失败，不选块、补齐、插值或自动排序。

#### Scenario: 无资料执行合法输入
- **WHEN** 任务提供合法单块 RGB 或 YUV PPG、固定模型且参数为空，未提供健康资料和客户端元数据
- **THEN** 算法允许进入实际计算，公开 `isExample=false`，不要求 ACC 或其他传感器文件

#### Scenario: 输入无法执行
- **WHEN** 输入缺列、通道组不完整或同时存在、数值非有限、时间轴不严格递增、多块记录，或长度及采样率不足以执行固定处理
- **THEN** 算法报告 `INFERENCE.INVALID_INPUT` 及受控原因，不生成风险概率或分类

#### Scenario: 拒绝改变固定解释
- **WHEN** 发布或执行提供质量阈值、滤波、特征选择或风险阈值等未声明参数
- **THEN** 系统拒绝参数，不静默替换 v1 固定规则

### Requirement: 糖尿病风险 v1 保持整段特征解释与模型配套
糖尿病风险 v1 MUST 固定迁移基线的颜色转换、预处理、整段生物标志物统计及 918 维 float32 特征语义和顺序，不改用滑窗、任务间拟合或血氧特征。制品 MUST 与该输入及已核验的糖尿病类别概率输出相容；不相容制品 MUST 以 `INFERENCE.INVALID_ARTIFACT` 终止。特征退化 MUST 按已核验基线处理，不以补零、裁列、默认预测或吞掉程序异常制造成功。

#### Scenario: 特征语义保持一致
- **WHEN** 同一固定可用采集样本分别运行已记录的旧版基线和新实现
- **THEN** 新实现的特征名称与顺序一致，波形、质量分数、特征和概率在经定位解释的浮点容差内一致，不能只用特征宽度相同证明兼容

#### Scenario: 模型输入或概率输出不配套
- **WHEN** 制品输入宽度不为 918、类型或结构不匹配，或不能按已核验类别映射提取目标概率
- **THEN** 资源准备以 `INFERENCE.INVALID_ARTIFACT` 失败，不选择任意输出列继续计算

#### Scenario: 计算故障不变成特征退化
- **WHEN** 特征依赖缺失、导入失败或发生未预期程序异常
- **THEN** 任务按受控执行失败终止，不补零继续预测，也不伪造质量拒绝

### Requirement: 糖尿病风险 v1 在特征计算前执行实际质量门禁
糖尿病风险 v1 MUST 使用预处理后 PPG 的实际质量分数和固定阈值 70；严格低于 70 时 MUST 以 `LOW_SCORE` 及原始分数、阈值终止，在特征提取、模型推理和成功输出之前拒绝。分数等于 70 允许继续，但不保证计算成功。非法评分和意外异常 MUST NOT 补为零分、满分或默认 `NO_VALID_SIGNAL`。

#### Scenario: 评分低于阈值
- **WHEN** 实际评分为 69.999
- **THEN** 报告 `LOW_SCORE`，保留 69.999 和 70，不进入特征提取或推理，不产生成功文件与指标

#### Scenario: 评分达到阈值
- **WHEN** 实际评分为 70 且其他执行条件满足
- **THEN** 允许进入特征计算，后续失败仍不能保存成功结果

#### Scenario: 评分无效
- **WHEN** 评分为空、含非有限值或评分器发生意外异常
- **THEN** 按执行或契约错误终止，不伪造评分或质量结论

### Requirement: 糖尿病风险 v1 先验证原始概率再执行三分类
糖尿病风险 v1 MUST 为单个任务提取恰好一个有限且位于 `[0, 1]` 的原始目标类别概率 `prob`。空输出、错误形状、数量不匹配、非有限或越界概率 MUST 以 `RESULT.INVALID_OUTPUT` 终止，不限幅或补值。合法概率 MUST 原精度保留；分类使用与 ECMAScript `Number(prob.toFixed(2))` 相同的值 `p`，`p < 0.66` 为整数 0（低风险），`0.66 ≤ p < 0.76` 为整数 1（中风险），`p ≥ 0.76` 为整数 2（高风险），字段名为 `risk_level`。

#### Scenario: 返回概率与三分类
- **WHEN** 原始概率为 0.2、0.72381、0.9
- **THEN** `prob` 分别原样保留，`risk_level` 分别为 0、1、2

#### Scenario: 舍入后跨越分类边界
- **WHEN** 原始概率依次为 0.654、0.655、0.659、0.754、0.755、0.759
- **THEN** 分类分别为 0、1、1、1、2、2，原始概率不被舍入值覆盖，也不直接按原始概率比较阈值

#### Scenario: 概率与分类端点
- **WHEN** 原始概率依次为 0、0.66、0.76、1
- **THEN** 分类分别为 0、1、2、2；分类字段必须是整数而非布尔值或字符串

#### Scenario: 无效概率不得被分类掩盖
- **WHEN** 原始概率为 NaN、正负无穷、负数或大于 1，或预测结构不符合单任务概率输出契约
- **THEN** 整个结果拒绝，不产生概率投影、风险分类或成功输出

### Requirement: 糖尿病风险 v1 返回一致结果与受保护波形
糖尿病风险 v1 成功结果 MUST 同时包含未舍入 `prob`、`risk_level` 和实际质量信息。可投影概率代码 MUST 为 `diabetes_probability`，类型为 number，单位为 `ratio`，数值与 `prob` 一致；分类保留在完整结果中。成功执行 MUST 输出逻辑名 `processed_ppg` 的 CSV，保留毫秒时间轴与对应处理后信号，文件仅通过既有受保护下载提供，不暴露本地绝对路径。结果 MUST NOT 被表达为血糖浓度或确诊结论。

#### Scenario: 查询与下载成功结果
- **WHEN** 任务成功且版本选择投影 `diabetes_probability`
- **THEN** 任务详情同时提供概率、分类与质量信息，指标等于未舍入概率，所有者可下载与该任务对应的处理后 PPG

#### Scenario: 拒绝越权访问波形
- **WHEN** 其他用户或不匹配渠道请求输出文件
- **THEN** 沿用任务所有权与渠道检查拒绝访问，不因新增算法公开健康数据

#### Scenario: 版本与相邻任务隔离
- **WHEN** 不同输入任务交错使用两个模型发布版本，渠道在执行期间切换版本
- **THEN** 每个任务使用自身冻结版本，概率、分类、质量和文件均属于本次调用，不继承其他任务状态
