# Spec Delta

## ADDED Requirements

### Requirement: 正式文件发布以成功提交为准
执行 MUST 在令牌隔离的目录中生成并校验完整输出，成功事务 MUST 登记该执行的不可变实际文件引用。只有数据库已经提交成功的文件集合才能发布到稳定正式目录。失败、失租、回滚和重复消息 MUST NOT 改写正式输出，既有终态不可重提规则 MUST 保持。

#### Scenario: 旧执行晚于新执行完成
- **WHEN** 旧执行继续写自己的临时输出，而新执行已提交成功并发布
- **THEN** 旧执行不能改变正式目录或已提交文件字节，下载仍返回新执行的成功结果

#### Scenario: 结果事务回滚
- **WHEN** 计算完成但成功结果或指标事务回滚
- **THEN** 本次文件不进入正式目录，不产生权威下载引用，已有正式文件不变

#### Scenario: 质量拒绝或算法失败
- **WHEN** 算法拒绝质量或报告执行错误
- **THEN** 不发布本次工作目录，即使其内已存在文件也不能成为成功结果

### Requirement: 发布中断可由权威成功记录恢复
稳定目录发布 MUST 幂等，且以数据库已提交的完整成功文件集合为唯一依据。成功提交后发布前退出或发布 I/O 失败 MUST NOT 将任务改为失败；后续结果下载或终态消息处理 MUST 尝试恢复发布而不重新计算。下载 MUST 读取已经登记的不可变成功文件，发布缺失不得导致读取另一执行的内容。

#### Scenario: 成功提交后进程退出
- **WHEN** 数据库已保存成功结果，但进程在发布正式目录前退出
- **THEN** 后续下载或终态消息处理依据成功记录重建正式目录，不重新运行算法、增加执行次数或改变结果指标

#### Scenario: 发布失败后再次处理
- **WHEN** 正式目录发布发生暂时 I/O 错误，之后存储恢复
- **THEN** 成功状态保持，安全记录发布失败；后续幂等恢复发布，实际文件缺失时下载按安全资源不存在处理

#### Scenario: 发布与下载并发
- **WHEN** 正式目录更新期间发生已授权下载
- **THEN** 下载打开数据库权威引用的完整文件，不跟随更新中的路径读到其他执行内容；路径公开不替代账号和渠道检查
