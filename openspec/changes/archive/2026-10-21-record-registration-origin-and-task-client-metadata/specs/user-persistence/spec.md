# Spec Delta

## ADDED Requirements

### Requirement: 随新账号持久化注册来源渠道
系统 MUST 将新账号首次注册所用的普通 API 渠道与账号及空资料一并持久化。若来源渠道不能保存，注册 MUST 回滚，不得留下缺少注册来源的新账号；无法确认来源的历史账号 MUST 保持未知，不得推断或伪造来源。

#### Scenario: 原子保存注册渠道
- **WHEN** 用户通过 `ios-cn` 成功注册
- **THEN** 账号、空资料和 `ios-cn` 注册来源同时持久化

#### Scenario: 注册来源持久化失败
- **WHEN** 注册过程中无法持久化本次普通渠道来源
- **THEN** 注册事务回滚，账号和对应空资料均不保留

#### Scenario: 迁移已有账号
- **WHEN** 历史账号没有可验证的注册渠道
- **THEN** 其来源保持未知，不将默认渠道或迁移时的当前渠道写作真实来源
