## 2. 请求关联与异步隔离

- [x] 2.1 实现 ASGI 兼容的每请求标识和安全上下文，响应写入 `X-Request-ID`，完成时仅记录一次请求结果；以 HTTP 测试验证匿名、404、已知 4xx 及成功请求的标识、真实状态和可解析日志一致，伪造的客户端请求标识不能覆写服务端值。
