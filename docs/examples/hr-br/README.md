# 合成 PPG 示例数据

`ppg.csv` 是由固定规则生成的合成示例，不包含真实人员、病史或采集记录，仅用于检查文件解析和服务流程，不用于临床或健康判断。

列 `timestampFrame` 是毫秒时间戳；`avgR`、`avgG`、`avgB` 是 RGB 通道的合成平均强度值。数据有 10 行，每行间隔 100 ms。按从 0 开始的行号 `i` 生成：`timestampFrame = 100 × i`、`avgR = 120 + 2 × (i mod 5)`、`avgG = 128 + (i mod 7)`、`avgB = 136 + 3 × (i mod 4)`。

示例执行器只从实际文件计算样本数、时间跨度和采样率；这些诊断不是心率或呼吸率预测，也不证明任何医学算法准确性。
