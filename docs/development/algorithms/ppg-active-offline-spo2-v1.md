# PPG 主动离线血氧 v1

算法标识：`ppg.active.offline.spo2.v1`。实现目录：`packages/health-inference/src/health_inference/algorithms/ppg_active_offline_spo2_v1/`。算法为正式实现（`isExample=false`），只接受 `ppg` 输入，不要求健康资料、客户端元数据或非空参数。共享 CSV 读取与通道、时间轴校验位于 `health_inference/utils/ppg_input.py`。

## 输入格式与执行条件

输入为 UTF-8 CSV（可带 BOM），至少包含有限、严格递增的毫秒时间戳 `timestampFrame`，以及恰好一组完整 RGB 或 YUV 通道：

| 格式 | 必需列 |
|---|---|
| RGB | `avgR`、`avgG`、`avgB` |
| YUV | `avgY`、`avgU`、`avgV` |

表头不得重复，行列数必须一致。`blockIndex` 可省略；存在时每行必须为整数 `0`。缺列、两组通道同时出现、非有限值、非递增时间戳、多块布局均拒绝；不选块、不合并、不插值或补齐。

至少 450 帧才能形成一个窗口；根据时间戳间隔均值并按旧规则保留两位小数计算采样率，采样率必须大于 `8 Hz`，以满足最高 `4 Hz` 带通截止频率的 Nyquist 前提。采样率或数据长度不足时报告受控输入错误，不尝试重采样或修复采集数据。

## 固定计算链

YUV 按旧 BT.709 矩阵转换并将 RGB 除以 `255`；RGB 输入的特征通道保留原量级。PPG 波形取负红通道（RGB 为 `-avgR / 255`，YUV 为转换后 `-R`），经过二阶 Butterworth `0.75–4 Hz` 带通、`filtfilt` 和总体标准差 Z-score。质量评价与特征计算复用同一份预处理结果。

特征阶段按 R、G、B 顺序构建九通道：三路颜色值及各路 AC/DC。窗口固定为 `450` 帧、步长 `75` 帧、关闭差分；窗口数为 `floor((样本数 - 450) / 75) + 1`，起点以输入样本索引表示。每窗按旧链计算基础时域、频域、峰值、AC/DC 与比值特征，并尝试使用 vendored pyPPG 提取生物标志物。pyPPG 使用 `125 Hz` 内部重采样；短于 `15 秒`、近似常量或无特征点时仅退化为基础特征。依赖故障和未预期异常不能当成退化后继续生成成功结果。

完整特征矩阵按 `feature_names` 的顺序构造，仅清单缺失的特征填零；稳定列严格按 `stable_features` 顺序选择。当前任务内执行 `StandardScaler`，随后逐列使用旧 Min-Max 公式 `(X - min) / (max - min + 1e-8)`，作为 `float32` 输入 ONNX。一个窗口时任务内标准化和归一化结果为零，这是保留的旧行为与已知限制，不跨任务借用统计量。

## 模型制品

正式版本要求且仅接受以下三个制品逻辑名：

| 逻辑名 | 内容 |
|---|---|
| `spo2` | 单输入、单输出的 ONNX 模型；输入为动态批量的二维 `float32` 特征矩阵，输出每窗口一个标量 |
| `feature_names` | UTF-8 JSON 字符串数组，完整特征名称及其原始顺序 |
| `stable_features` | UTF-8 JSON 字符串数组，稳定特征名称及其模型输入顺序 |

两份 JSON 数组必须非空、无重复，且每个稳定名称都必须存在于完整名称数组；稳定名称数必须与 ONNX 输入宽度匹配。模型节点类型和输出维度也须符合契约。正式路径只解析 JSON，不反序列化 pickle 或其他可执行对象；文件名不决定逻辑名或算法版本。

## 质量门禁与错误

质量门禁在窗口特征和模型调用之前执行。它调用 NeuroKit2 `ppg_quality` 评价处理后 PPG，采样率按旧链传 `int(fs)`，实际分数为返回值均值乘以 `100`，不舍入。分数严格小于 `70` 时以 `INFERENCE.QUALITY_REJECTED` 和 `LOW_SCORE` 拒绝，并保留实际分数及阈值；恰好 `70` 允许继续。空、非有限评分或意外异常不能补成零分、满分、质量拒绝或成功结果。

模型输出必须是一维 `[N]` 或单列 `[N, 1]`，非空、窗口数量一致且全部有限。任何形状、数量或有限性错误均以 `RESULT.INVALID_OUTPUT` 终止，不丢弃坏窗口，也不先限幅掩盖无效值。其余输入按 `INFERENCE.INVALID_INPUT` 及受控原因处理；不兼容制品使用 `INFERENCE.INVALID_ARTIFACT`；不接受非空版本参数。

## 成功结果与处理文件

完整结果包含有限的 `spo2`、实际质量信息、未限幅的逐窗口预测和对应的样本起点。聚合先取原始窗口预测最大值，再限幅到 `[90, 100]`；不取均值、不舍入。`spo2` 指标使用与完整结果相同的最终数值，类型为 `number`，单位为 `percent`。原始预测保持不变，例如预测 `[85, 103]` 时，完整结果保留 `[85, 103]`，最终 `spo2` 和指标均为 `100`。

成功详情通过 `result.output_files.processed_ppg` 返回不透明文件引用。该逻辑名对应本次执行专属 `output_dir` 内的 `ppg-processed.csv`，表头为 `timestampFrame,ppg`；时间戳保留输入毫秒值，处理后 PPG 与输入帧逐行对应。结果载荷不包含本地绝对路径，文件下载沿用任务所有权和渠道检查。

## 解释限制与测试资料

该算法仅按既定数据和模型契约执行，不构成医学诊断、医学器械认证或准确性证明。单窗口全零输入、窗口最大值聚合和 `[90,100]` 限幅均为已知限制；不得将最终限幅后的相等误报为特征链一致或医学效果。

仓库本地 `var/old-assets/` 及其中的 PPG 样本是测试资料，不是生产模型或初始数据库种子。安全转换后的清单只能用于显式测试；不得将这些文件、样本或凭文件名推断出的算法选择写入产品初始化、公开样例或生产渠道配置。

### 真实消费者与隔离工作流

本机真实服务 smoke 使用隔离的任务存储、测试 Redis 命名空间和持久测试数据库，经管理 API 上传 ONNX 与安全转换后的 JSON 清单、发布测试版本，再以普通测试身份提交本机样本并运行消费者。任务实际进入 `SUCCEEDED`；质量分为 `88.658667`，7 个窗口预测，`spo2` 结果与指标均为 `94.64368438720703`。所有者下载得到与 929 帧输入逐行对应的 `timestampFrame,ppg` CSV；同渠道其他用户下载返回 `404`，Redis pending 数为 `0`。验证后清理测试任务、模型元数据、Redis 键和隔离文件；未记录令牌、改动生产渠道或新增原始 PPG 副本。

永久工作流测试使用确定性合成 PPG 和运行时生成的 ONNX 模型，不依赖本机旧仓库或私有制品。测试按 A、B、A、B 顺序提交并执行四个相邻任务，核对固定版本、结果与各自输入波形、输出键互异、渠道当前选择及已发布版本时间未被回写、越权下载拒绝；非有限窗口预测任务失败，且没有成功载荷、指标投影或处理后 CSV。

命令 `uv run --locked --all-packages --extra ppg pytest --reuse-db tests/unit/inference tests/unit/test_execution_failure_mapping.py tests/unit/test_inference_algorithms.py tests/unit/test_inference_quality.py tests/integration/workflows -q` 结果为 `235 passed, 125 warnings`（53.50 秒）。警告来自 vendored pyPPG 的 NumPy 转换弃用、NeuroKit2 对 `scipy.misc` 的弃用引用，以及近似信号的偏度/峰度精度提示。`uv lock --check` 和相关算法、适配器及测试文件的定向 Ruff 检查通过；仓库全量 Ruff 仍报告 vendored pyPPG 与既有迁移文件的风格问题，本次未改动这些无关内容。
